# Installation

## Stable release

To install RateKing, run this command in your terminal:

```sh
uv add RateKing
```

Or if you prefer to use `pip`:

```sh
pip install RateKing
```

## From source

The source files for RateKing can be downloaded from the [Github repo](https://github.com/phfmatias/RateKing).

You can either clone the public repository:

```sh
git clone git://github.com/phfmatias/RateKing
```

Or download the [tarball](https://github.com/phfmatias/RateKing/tarball/main):

```sh
curl -OJL https://github.com/phfmatias/RateKing/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd RateKing
uv pip install .
```
